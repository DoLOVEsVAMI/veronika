# CASE 20.05

Мобильный интерактивный романтический квест: 16 сцен, локальные головоломки, фото- и аудиоулики, сохранение прогресса и два бережных финала.

## Запуск

Требуется Node.js 20 или новее.

```bash
npm install
npm run dev
```

Vite покажет локальный адрес, обычно `http://localhost:5173`.

Проверка production-сборки:

```bash
npm run lint
npm run build
npm run preview
```

## Где менять содержание

Основные тексты, вопросы, варианты ответов, даты, подписи фото и финальное приглашение находятся в:

```text
src/app/content.ts
```

Скрытое слово и распределение букв по сценам находятся в `src/app/constants.ts`. Тексты отдельных визуальных сцен — в соответствующих файлах `src/scenes/Scene*.tsx`.

## Как добавить фотографии

Положите изображения в каталог:

```text
public/photos/
```

По умолчанию приложение ищет `photo-01.jpg` … `photo-05.jpg`. Имена и подписи меняются в массиве `photoClues` файла `src/app/content.ts`. Если файл отсутствует, вместо сломанного изображения показывается стилизованный архивный placeholder.

Фоновые изображения при желании можно положить в `public/backgrounds/` и подключить в `src/styles/globals.css`. Предусмотрены имена `cemetery.jpg`, `abandoned-house.jpg`, `fog-forest.jpg`, `pink-room.jpg`, `final-forest.jpg`; текущая версия полностью работает на CSS-фонах и без них.

## Как добавить музыку

Положите аудиофайл сюда:

```text
public/audio/track.mp3
```

Путь меняется в поле `audioTrack` файла `src/app/content.ts`. Автовоспроизведения нет: запись запускается только по нажатию пользователя. Если файла нет, квест показывает fallback и позволяет продолжить.

## Публикация на GitHub Pages

1. Создайте GitHub-репозиторий и загрузите проект в ветку `main`.
2. На GitHub откройте **Settings → Pages**.
3. В разделе **Build and deployment → Source** выберите **GitHub Actions**.
4. Отправьте изменения в `main` или вручную запустите workflow **Deploy to GitHub Pages**.

Имя репозитория в `base` подставляется автоматически во время GitHub Actions-сборки.

Workflow находится в `.github/workflows/deploy.yml` и автоматически устанавливает зависимости, собирает `dist` и публикует его.

## Технические детали

- React + TypeScript + Vite + Framer Motion.
- Прогресс сохраняется в `localStorage`; кнопка `↺` начинает расследование заново.
- Интерфейс учитывает safe-area iPhone, использует `100dvh`, touch-target кнопки и reduced motion.
- Все ассеты локальные, backend и внешние API не нужны.
